## Preguntas Frecuentes

### ¿Qué es Angular?
Angular es un framework de desarrollo frontend de código abierto, basado en TypeScript y respaldado por Google. Permite construir aplicaciones web modernas, escalables y de una sola página (SPA - Single Page Application) utilizando una arquitectura basada en componentes.

### ¿Qué herramientas necesitan instalar?
Para comenzar a desarrollar y ejecutar este proyecto en tu computadora, necesitas tener instalado lo siguiente:
1. **Node.js**: Entorno de ejecución para JavaScript (incluye npm, el gestor de paquetes).
2. **Angular CLI**: Interfaz de línea de comandos oficial para gestionar proyectos de Angular. Se instala ejecutando:
   ```bash
   npm install -g @angular/cli
